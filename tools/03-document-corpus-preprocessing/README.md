# Document and Corpus Preprocessing Tools

This folder preserves selected scripts from earlier PyCharm work. They are useful supporting evidence for data preparation, but they are not the central research contribution.

## Included tool types

- PDF crop-box preparation for removing non-content page margins
- OCR preparation and page selection
- Text cleaning and paragraph normalization
- Chinese word segmentation and exploratory word-cloud visualization

## Responsible publication boundary

The original `PythonProject6` folder contains a large OCR-derived copy of a copyrighted novel. The source corpus is intentionally excluded from this repository. Only the preprocessing logic is suitable for public documentation, and it should be refactored to accept command-line paths before production reuse.

## Application relevance

These tools show early experience moving between unstructured documents, cleaned text, corpus materials, and visual inspection. They support the stronger evaluation projects by demonstrating practical data preparation skills.
