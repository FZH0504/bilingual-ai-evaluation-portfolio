# Fu Zhihan | Bilingual AI Evaluation & Learning Technology

This repository organizes selected undergraduate research and prototype work for graduate applications, research assistant outreach, and AI evaluation / EdTech opportunities.

The portfolio is organized around a common research question: how can multilingual language data be prepared, evaluated, and turned into interpretable evidence for learning and feedback systems?

## Research Areas

- Bilingual Chinese-English LLM evaluation
- Multilingual learners and bilingual reading support
- Corpus construction and text alignment
- Statistical benchmarking and reproducible analysis
- AI-assisted writing / speaking feedback
- Educational NLP and learning analytics

## Projects

### 1. LLM Translation Evaluation Pipeline

An auditable workflow for paired bilingual data validation, COMET scoring, transparent text metrics, external linguistic feature import, and paired statistical analysis.

See [`research/01-llm-translation-evaluation/`](research/01-llm-translation-evaluation/).

### 2. Temporal Reliability of ChatGPT-Generated Bilingual Texts

A controlled longitudinal evaluation of four successive ChatGPT snapshots across finance, technology, and public policy, using COMET, readability, lexical, and discourse indicators.

See [`research/02-temporal-reliability-chatgpt/`](research/02-temporal-reliability-chatgpt/).

### 3. Document and Corpus Preprocessing

Selected scripts from earlier PyCharm work for PDF cropping, OCR preparation, text cleaning, and exploratory word-cloud visualization.

See [`tools/03-document-corpus-preprocessing/`](tools/03-document-corpus-preprocessing/).

## Public Data Policy

The repository contains code, documentation, derived figures, and small summary tables. It does not include private questionnaires, unpublished raw participant data, local virtual environments, logs, API keys, or the full copyrighted OCR corpus used during early text-processing experiments.

## Positioning

I am an undergraduate English major working at the intersection of bilingual language expertise, LLM evaluation, corpus-based analysis, learning technology, and AI-assisted feedback. My role has focused on data preparation, evaluation tooling, analysis support, and interpretation rather than model development from scratch.
